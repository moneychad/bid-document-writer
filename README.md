# Bid Document Writer

Hermes Agent Skill：解析招标文件、撰写投标文件、审核投标响应的完整工作流。

## 功能

- **五阶段工作流**：解析 → 素材收集 → 撰写 → 审核 → 交付
- **六步读标法**：资格审查 → 评分标准 → 附表 → 技术要求 → 商务条款 → 格式要求
- **结构化提取**：10类信息自动解析（项目信息、资格要求、评分标准、技术要求等）
- **格式验证**：中文字体/字号检查、页面布局验证、页码连续性检查
- **审核清单**：合规性 + 格式 + 一致性三维度审核
- **19条 Pitfalls**：覆盖扫描件OCR、模板残留、业绩三件套、中文字体陷阱等

## 安装

```bash
# 最小安装（覆盖80%功能）
bash setup.sh

# 完整安装（含LibreOffice + docformat-gui）
bash setup.sh --full
```

## 使用

加载 skill 后按五阶段工作流执行：

1. **解析招标文件** — 提取全文 → 结构化要求 → 生成要求清单
2. **收集素材** — 向用户索要资质、业绩、技术方案等材料
3. **撰写投标文件** — 逐章撰写 + 偏离表
4. **审核** — 合规性/格式/一致性三维度审核
5. **交付** — 输出 Markdown 或 Word 格式
